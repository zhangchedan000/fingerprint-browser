# 内核显卡清单

指纹内核内置一份真实显卡清单，启动时按 `种子 % 清单长度` 选一块。作者从 148 版起不再公开源码，
所以清单靠实测得到：用种子 0、1、2… 依次启动内核，读出 WebGL 显卡信息，直到整份清单完整重复两遍。

结果保存在 `src/shared/gpu-catalogs.json`（按内核主版本存）。软件据此：

- 编辑窗口时列出所有显卡，并标出哪些内核版本里有；当前窗口内核没有的显示为灰色；
- 启动时按窗口实际使用的内核版本算出种子，保证报出的就是选中的那块显卡；内核里没有就拒绝启动，不会悄悄换卡。

## 内核出新版本时

下载该版本的 Linux 包（`ungoogled-chromium-<版本>-1-x86_64_linux.tar.xz`），解压后在项目根目录运行：

```bash
node tools/gpu-catalog/probe.mjs --chrome <解压目录>/chrome --version <完整版本号>
```

每个版本约 1–3 分钟。清单在各系统上相同，所以用 Linux 包测出的结果 Windows 和 macOS 也适用。
