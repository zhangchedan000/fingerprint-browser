## 修复

- **登录状态上传失败**：登录数据超过约 6 MB 的窗口，关闭后上传登录状态时提示「连不上团队服务器（The value of "delay" is out of range…）」，登录状态没传上去。原因是上传的等待时间按文件大小算出了带小数的毫秒数；现在取整，能正常上传。**更新后把受影响的窗口打开再关闭一次**，最新的登录状态就会传上去。
- **代理 IP 的时区**：不同 IP 数据库对同一个 IP 的城市经常判断不一（比如同一个 IP，4 个数据库说在美东、2 个说美中、1 个说美西）。以前取最先回应的那个，所以同一个代理这次检测是洛杉矶、下次是纽约，编辑页和检测结果互相矛盾。现在两个数据库时区不一样时，会再问其余的数据库，**按多数定时区**；出口 IP 卡片的「时区」后面会写明各数据库怎么分的。**更新后对代理重新检测一次**，就会按新规则得出时区。
