## 保存的窗口，指纹就固定了

- 以前窗口要第一次打开才固定，没打开过的窗口检测代理后国家还会跟着变。现在**点保存就固定**：之后换 IP、检测代理、打开窗口，都只提醒国家对不上，并给一个「改成和 IP 一致」按钮，不会自己改。
- 新建窗口的规则不变：检测到代理 IP 后，国家、时区、语言、位置、字体、语音自动按 IP 配好。
- 老窗口升级后自动固定：有检测结果的按检测结果（标「基于 IP 生成」），没有的按原来的值（标「手动选择」）。系统语言、语音、设备名语言、媒体设备也都写进窗口，以后的版本不会再改它们。
- 国家下面几行和国家显示的永远是同一套值。
- 检测到的是**轮换 IP**（每个连接换一个出口）时，不拿它配置国家和语言，只提醒。

## 国家与语言

- 时区、浏览器语言改成下拉框，默认就是跟国家配套的值；浏览器语言里标出这个国家默认的那个。
- 「随系统语言」拆成**语音**和**媒体设备名**两行，各自一个下拉框，默认跟随系统语言。
- 换国家时，下面单独改过的几行一起恢复成跟国家配套。
- 单独选的时区或语言和国家对不上时，那一行下面黄字提醒，不拦。

## 填完代理自动检测

- 新建窗口粘贴代理、填完地址和端口（停 1 秒）、从代理库选中、粘贴 API 链接，都会**自动检测**，检测成功就自动配好国家和语言，不用再点「检测代理」。
- 从代理库选的代理有上次检测结果的，先按它配好，同时在后台再测一次。
- 「检测代理」按钮还在，想重测随时点。

## API 提取

- 取到的代理**一直用到不能用了才换**，不再每次打开都取新的：账号一直在同一个 IP 上，也不浪费提取次数。
- 代理设置里显示「当前 IP」：IP、国家城市、代理地址、什么时候取的；加了「**换一个 IP**」按钮，想换随时换。
- 编辑页检测、新建时检测取到的 IP 都会留下来用，也记进 IP 使用记录。
- 打开窗口时，IP 不在窗口的国家（或是轮换 IP），自动从链接重新取，**最多 3 次**；还不对再问你要不要继续。
- API 窗口不再显示「出口变化时」，换 IP 对它是正常的。

## 媒体设备、分辨率

- 媒体设备改成几种真实的台式机配置，**每项都写清数量**，比如「麦克风 1 · 扬声器 1 · 耳机 1 · 摄像头 0（音箱 + USB 耳麦）」。
- 「自动」按显卡档次选：入门卡是只接音箱或只有耳麦，中高端是 USB 耳麦，旗舰卡也可能带摄像头。保存后固定。
- 分辨率下拉框里，和这块显卡常见搭配的排在前面，标「常见」；手动选了不常见的（比如入门显卡配 4K），黄字提醒。

## Canvas / AudioContext / ClientRects 实际值

- 新窗口保存后，在后台自动检测一次，以后打开编辑页直接看到网站读到的值。
- 改时区、语言、代理不再把这三个值标成「设置已修改」，只有种子、显卡、内核变了才算过时。检测过的老窗口，值会重新显示出来。

## 换电脑打开云端窗口

在电脑 A 配好的窗口，到电脑 B 打开时：

- 窗口指定的**内核** B 上没有，自动下载安装再打开。
- 窗口开了**网络加速**，它用的节点随窗口一起同步到云端，B 上没有就自动添加，加速没开就自动开启。
- 窗口系统语言需要的 **Windows 字体包** B 上缺，自动下载（微软官方，不需要管理员权限）。
- **API 提取**的当前代理和 IP 记录一起同步，B 接着用同一个 IP。
- **保存的密码**跟着登录态一起同步（Windows 上把 Chrome 的密码钥匙转给 B 的用户），B 上不用重新填。
- 代理或 API 是 IP 白名单授权、换电脑后连不上时，提示把 B 的公网 IP 加白名单（开着网络加速时是加速节点的 IP）。

注意：Canvas 等值是显卡真画出来的，A、B 两台电脑的真实显卡一样就完全一样，不一样可能有差别。
