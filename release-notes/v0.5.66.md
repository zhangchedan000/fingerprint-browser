## 代理方式「订阅」

- 窗口编辑 → 代理设置：代理方式最后多了「订阅」（7 种方式排成一行）。选了以后两行：
  - **选择订阅**：列出所有订阅，显示类型、节点数、几个窗口在用；下拉底部可以直接添加订阅。
  - **选择节点**：这个订阅里的节点，显示节点名、协议、国家和 IP、延迟、几个窗口在用，可以搜索。别的窗口也在用同一个节点时，黄色提示共用出口 IP 的关联风险。
- **网络加速开关照旧**，自己决定开不开。开的时候可以「自动」，也可以**手动固定某个加速节点**，每个窗口各走各的。
- Hysteria、TUIC 这类走 UDP 的节点也能经过网络加速。前提是选的加速节点能转发 UDP；不能的话编辑页会提示换一个，连不上时就是连不上，不会绕开加速、不会直连。
- 窗口选的节点在订阅更新后不见了：打开窗口时提示重新选，不会悄悄换成别的节点，也不会直连。

## 代理 IP → 订阅

- 代理 IP 页面顶部分「代理 / 订阅」两个标签，「代理」和以前一样。
- 「订阅」：订阅总数、节点总数、可用、失效；添加订阅、全部刷新、全部检测、搜索（订阅 / 节点 / IP）。
- **订阅可以加很多个**，每个一行（名称、类型、节点数、绑定窗口、最后更新、检测 / 编辑 / 删除），展开看每个节点的协议、出口 IP 和地区、延迟、状态、绑定窗口，可以单个检测。
- 添加订阅：粘贴订阅链接，或者粘贴节点链接（一行一个）。订阅名称不能重复；改名后，用它的窗口自动跟着改。
- 节点的检测、IP 评分、「几个窗口在用」、打开窗口前的出口 IP 检查，都和代理库里的代理一样。
- 订阅和窗口选的节点跟着账号走，其他电脑登录同一个账号也能用。

## 验证

- 单元测试 463 个、类型检查全部通过。
- 用真实代理内核做了端到端测试（本机搭的测试节点，包括一个走 UDP 的节点）：窗口从选中的节点出去；开网络加速时自动、固定某个加速节点都先经过那个加速节点；新加一条加速路线时其他窗口不断；UDP 节点经过网络加速能通，经过不转发 UDP 的加速节点时报错、不直连；节点或订阅不存在时报错；同名订阅被拒绝。
