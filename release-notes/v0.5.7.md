## 修复

- **更新到 v0.5.5 / v0.5.6 后启动失败**：v0.5.5 把启动器自身的缓存挪进了数据目录，但解密已保存密码用的钥匙也在那个缓存里，挪过去之后用的是一把新钥匙，旧数据解不开，软件就拒绝启动。你的数据没有被改动。
  - 这一版把缓存放回原处，用回原来的钥匙，直接装上就能正常打开。
  - 已经打不开的电脑：下载 **Fingerprint-Browser-Setup-0.5.7.exe** 覆盖安装即可（打不开就没法在软件里点更新）。
  - 在 v0.5.5 / v0.5.6 上新装的电脑也能照常打开。
- 启动器缓存因此仍在 C 盘（不大）；窗口数据、内核、下载位置都照常可以放 D 盘。
