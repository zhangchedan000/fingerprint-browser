## 改动

**内核管理**
- 当前内核那一栏显示装的是哪一版 Prism 指纹内核（按内核文件里的 prism 号，比如 prism11）。以前写死「Prism 内核 + 12 个指纹补丁」，那是很早的版本，现在是 15 个补丁。
- 去掉「自己编译内核」卡片：内核的补丁和编译包早就不在这个仓库，这张卡片指向的是旧的一份。内核照常在「内核管理」里下载和更新。

**仓库清理（不影响使用）**
- 删掉旧的内核补丁和编译脚本（`tools/kernel-patches`、`windows-kernel`、`macos-kernel`、`kernel-maintenance`、`kernel-lock.json`）、把内核复制到本仓库发行版的旧流程、已经失效的指纹矩阵测试，以及过时的文件清单和 0.1.1 的旧说明。需要时都能在 git 历史里找回。
- 内核单独发布在 [prism-kernel-releases](https://github.com/zhangchedan000/prism-kernel-releases/releases)；本仓库只放启动器。以前放在本仓库发行版里的旧内核（prism8 及更早）保留不删，旧版启动器照常能下载。
- README 改成现在的功能说明。
