## 修正

- **「时区不在这个国家」的一键改选错了时区**：IP 不在这个国家时，v0.5.21 会改成这个国家时区列表里的第一个，而列表是按 UTC 从西往东排的，美国会被改成夏威夷时间。现在改成这个国家最常见的时区（首都所在地）：美国是纽约，加拿大是多伦多，澳大利亚是悉尼，巴西是圣保罗，俄罗斯是莫斯科，墨西哥是墨西哥城。
- **IP 时区按 Windows 的叫法比较和修改**：IP 数据库给的时区名有时和 Windows 上 Chrome 报告的不同，比如 IP 在底特律，数据库给 America/Detroit，Windows 上的 Chrome 报告 America/New_York，两者其实是同一个时区。以前检测会把这种情况误报成「时区不一致」，一键改还会改成 Windows 里没有的名字；现在按 Windows 的叫法比较，一键改也改成 Windows 的叫法。Windows 上没有对应时区的（全世界只有南极的 Antarctica/Troll 一个），不给一键改按钮。

## 核对范围

新增的测试逐个跑过：
- 200 多个国家：一键改设的时区都在这个国家的时区列表里，改完提示消失；
- 每个国家的每个时区：IP 在这个国家时，保留 IP 自己的时区；
- 全部 418 个 IANA 时区：都换算成 Windows 上 Chrome 报告的叫法；
- 150 多个国家的常用语言：改完「语言和国家对不上」的提示消失；
- 每块可选显卡、4 种屏幕缩放：一键改给的分辨率都是这块显卡常见的、且在分辨率列表里。
