## 软件更新

- **一键更新**：「设置 → 关于」检查新版本，显示更新内容，下载后校验 SHA-256，点“立即重启并更新”替换当前 exe（位置不变，快捷方式照常用）。侧栏版本号旁有新版本提示。
- **语言按真实数据**：
  - 国家 → 语言用 CLDR（Chromium 自带的 ICU 数据）；
  - 界面语言按 Chrome 自己的规则选（如墨西哥 → es-419、澳大利亚 → en-GB、香港 → zh-TW）；
  - navigator.languages / Accept-Language 用 Chromium 156 源码里各语言的默认值（IDS_ACCEPT_LANGUAGES），例如日语是 `ja,en-US,en`，和真实的日文 Chrome 一致；
  - 语言下拉框就是 Chrome 的界面语言列表，标出哪些有微软语音、设备名；
  - 「界面语言」可以单独选，默认跟随语言。
- **小分辨率**：prism5 内核可以报比本机显示器小的分辨率（如 2K 屏上报 1920×1080），窗口会被限制在这个分辨率里；按显卡匹配的分辨率也会选到 1080p。
- **内核**：一个发布里的多个内核都能列出；「历史版本」开关列出旧构建，可把已装内核原地退回。
- 媒体设备（麦克风/扬声器/摄像头）、语音、按显卡匹配的 CPU/内存/分辨率，每个窗口都可选，默认自动匹配。
- WebRTC“替换”显示代理出口 IP；内置加速通道可编辑来源、自动选节点；上次关闭的页面可以恢复。
- Windows 去掉了顶部菜单栏（编辑/视图/窗口/帮助）；程序和任务栏图标换成侧栏的蓝色指纹图标。

## 内核 prism5（相对 prism4）

- **新增补丁 015 小分辨率窗口限制**：报的分辨率比真实显示器小时，浏览器窗口始终在这块“屏幕”里——拖动、缩放不会超出；最大化铺满报的分辨率减任务栏（如 1920×1032）；F11 和视频全屏为报的分辨率（如 1920×1080）。报的分辨率不小于真实显示器时不受影响。
- 保留 prism4 的全部修改：媒体设备（014）、语音可指定（012）、WebRTC 替换（013）、Canvas、系统界面字体、Windows 真实语音、音频默认不加噪。

验证：2K 显示器上报 1920×1080，打开 1265×1032，强拉到 2400 宽被限制为 1920×1032，最大化 1920×1032，F11 全屏 1920×1080；报 2560×1440 时与原版 Chrome 相同。
