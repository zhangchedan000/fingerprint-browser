指纹浏览器 v0.5.13（Windows x64）。**修复 v0.5.12 打开窗口编辑页白屏**。内核没有变化，仍是 prism8。

## 下载

| 文件 | 说明 |
| --- | --- |
| **Fingerprint-Browser-Setup-0.5.13.exe** | 指纹浏览器安装包 |
| latest.yml、.blockmap | 软件自动更新用，不用下载 |
| SHA256SUMS | 安装包的 SHA-256 |

已经装了 v0.5.12 的话，在「设置 → 关于」点更新即可（白屏只出现在编辑窗口里，主界面能正常更新）。

**配套内核：prism8**，在内核仓库下载：[prism-kernel-releases / prism8](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/prism8)。

## 修复

- **编辑「国家/地区」是「基于 IP 生成」的窗口时整个界面变白**：编辑页里有一个值在准备好之前就被用到，界面直接崩溃。已修正。
- 「国家/地区」后面的「基于 IP 生成 / 手动选择」标签改为固定显示在下拉框右边，不会再被挤到下一行。

## 发版前多了一道检查

以后每次发版前，会在真实的软件里自动打开各种窗口（手动选国家、基于 IP 生成、API 提取、新建）的编辑页，把三个标签页都切一遍，出现白屏或报错就不发版。这一版已经用它确认：上一版的白屏能被它发现，这一版不再出现。
