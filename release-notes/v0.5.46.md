## 改动

- **字体不再装进 Windows**：prism16 内核自带 Win10 / Win11 两套系统字体、中文简体、阿拉伯文和 Windows 的后备字体规则。窗口语言需要别的字体包（日文、韩文、泰文等）时，启动器从微软官方下载到内核自己的目录，不装进电脑；和基础字体重复的文件不重复放。编辑页的字体行显示「这个语言的 Windows 字体由内核提供（需要时自动从微软官方下载），不装进电脑」。
- **系统版本号固定**（prism16 内核）：Win11 窗口报 19.0.0（内核自带的 Win11 25H2 字体），Win10 窗口报 10.0.0，不再跟着电脑（以前 22H2 电脑上报 15.0.0）。
- **屏幕缩放固定**：窗口按所选分辨率的缩放报（3840×2160 是 150%，其他 100%），不再跟着电脑。以前电脑设成 125% 时，1920×1080 的窗口会报缩放 1.25，和真 1920×1080 电脑对不上。电脑本身是 100% 时没有变化。
- **可用屏幕高度**：按窗口那版 Windows 的默认任务栏（Win10 40、Win11 48），不再用电脑自己的任务栏（自动隐藏、小任务栏、放侧边都会漏）。

旧内核（prism15 及以前）照旧可用，行为和 v0.5.45 一样。
