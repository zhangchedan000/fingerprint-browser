## 改动

- **团队功能重新打开**（v0.5.49 曾整个停用）：
  - **本地模式**：团队服务器连不上时（不是账号被停用），点左上角头像或登录页的「进入本地模式」，本机窗口照常开、照常改；团队窗口在本地模式里用过的，服务器连上后自动传上去。
  - **左上角头像**：小圆点显示服务器状态（绿：已连接，红：连不上，黄：本地模式），点开可以重试、进入本地模式、连接其它服务器。用着用着断了会在右下角提示一次。
  - **备用服务器**（主账号，团队页 →「服务器」）：填备用服务器地址和激活码，设为备用后所有成员的启动器会自动记住它。
  - **批量切换**（主账号）：一键把整个团队切到备用服务器：正在用的服务器停止写入、把最后的数据存到 R2（连不上就跳过），备用服务器从 R2 拉回全部数据后接班，成员的启动器自动跟过去。
  - **代理 IP 库和网络加速整份备份**：每个账号的整个代理库和网络加速节点也存到团队服务器（随 R2 备份），换电脑或换服务器后自动补回。
- **指纹参数加密**（配合 prism17 内核）：窗口的指纹参数、时区、语言、4K 缩放不再写在命令行上，而是加密后交给内核，内核读完就删；任务管理器等工具里看不到窗口的指纹设置。旧内核自动改用原来的方式。

## 验证

- 单元测试、类型检查全部通过；新加的测试覆盖：服务器挂了自动改连另一台、收到「已切换」后跟过去、本地模式不发任何请求且连上后补传用过的窗口、主账号设备用和批量切换、加密文件的内容和密钥。
- 服务器的整套切换在两台测试服务器上全流程跑过（正常切换、不经交接直接接班、旧服务器复活后自动让位、登录状态逐字节一致）。
- 在 Win11 电脑上用开发版启动器 + prism17 内核（156、155）实测：窗口所有进程的命令行里指纹参数 0 个，加密方式和原来的方式读到的指纹完全一样。
