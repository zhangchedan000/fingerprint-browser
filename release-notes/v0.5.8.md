指纹浏览器 v0.5.8（Windows x64）。**界面美化**：表格列宽可以拖动，状态标签统一，主题色可选，表格更紧凑。只改了界面，功能没有变化；内核没有变化，仍是 prism8。

## 下载

| 文件 | 说明 |
| --- | --- |
| **Fingerprint-Browser-Setup-0.5.8.exe** | 指纹浏览器安装包 |
| latest.yml、.blockmap | 软件自动更新用，不用下载 |
| SHA256SUMS | 安装包的 SHA-256 |

已经装了旧版的话，在「设置 → 关于」点更新即可。

## 列宽可以拖动

- 窗口管理、分组、代理、团队（云端窗口、成员、邀请码、日志、备份）、回收站等所有列表，鼠标移到表头两列之间的分隔线上，按住左右拖动就能调整列宽。
- 调好的宽度这台电脑会记住，下次打开还是这样。
- 在分隔线上**双击**，那一列恢复默认宽度。

## 主题和颜色

- 「设置 → 常规」新增**主题色**，6 种颜色可选，按钮、选中项、链接、标签页一起变色。
- 主题仍是「浅色 / 深色 / 跟随系统」三选一，「跟随系统」会随 Windows 的深浅色自动切换。浅色和深色都逐页检查过。

## 更好看、更紧凑

- **状态标签统一**：正常、已停用、空闲、正在使用、已在本机、邀请码状态、代理检测状态、备份同步状态，都改成同一种「圆点 + 文字」的圆角标签，颜色规则一致（绿＝正常，蓝＝信息，橙＝注意，红＝出错，灰＝未开始）。
- **窗口列表更紧凑**：代理一格从三行变成两行（协议和检测状态放在同一行），一屏能看到更多窗口。
- **提示条变薄**：「当前运行在兼容模式」等提示从大块改成细长条。
- **团队 → 云端窗口**：之前列太挤，「窗口」「分配给」几乎看不见，现在有固定宽度，可以左右滚动。
- 表格、卡片、统计块统一为更圆的边角和轻微的阴影，表头更清爽，鼠标悬停行有底色。
