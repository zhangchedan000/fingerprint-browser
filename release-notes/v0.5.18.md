## 检测代理

- **不再自动检测**：填代理、粘贴、切代理方式、开关网络加速、选代理库里的代理，都不会自己检测，只有点「检测代理」才测。以前网络加速还没来得及开就自动测了，结果是错的，API 窗口还白用一次提取。
- **检测结果一直保留**：切到别的页面、关掉编辑页再打开，上次的结果（成功、失败、轮换提醒）都还在，后面写着「检测于 …」。下次点「检测代理」才覆盖。
- 改了代理还没重新检测时，结果后面标黄字「代理已修改，未重新检测」，结果不清掉。
- 从代理库选代理时，直接显示这个代理上次的检测结果。
- 新建窗口点了检测，国家、时区、语言照常按 IP 配好。

## API 提取

- **显示提取到的地址和它的国家**：检测结果写成「提取 198.44.167.198:22413（US Los Angeles）→ 出口 78.179.144.99 · TR Bolu」。提取地址是服务商的服务器，网站看到的是后面的出口 IP，判断国家对不对还是按出口 IP。
- **检测记录**：每次提取和检测都记一条，成功、失败都记：时间、怎么触发的（检测代理 / 换一个 IP / 打开窗口）、是不是新提取的、提取地址和国家、出口 IP 和国家、轮换 IP 或失败原因。保留最近 50 条，随云端同步，在「IP 使用记录」下面，默认显示 5 条，可以展开。
- **检测到轮换 IP 不再重新提取**：打开窗口时发现是轮换 IP（每个连接换一个出口），不再从链接重取 3 次（这种链接取多少次都是轮换的，只会用掉提取次数），直接提示你改成固定会话（粘性 IP），由你决定要不要继续打开。IP 不在窗口的国家时还是会重取，最多 3 次。
- **白名单被拒时提示加白名单**：服务商因为这台电脑的 IP 不在白名单而拒绝连接（比如「msg: forbidden ip=… not supported」），提示把这台电脑的公网 IP（开着网络加速时是加速节点的 IP）加到服务商白名单，不再提示「检查代理类型」。

## 其他
