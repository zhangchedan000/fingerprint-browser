## 改动

- **检测前先装字体**：指纹检测、深度检测之前，和打开窗口一样先装好这个窗口要用的字体（系统语言字体包、另一个 Windows 的字体）。以前 Win10 电脑上的 Win11 窗口（或 Win11 电脑上的 Win10 窗口）没打开过就检测，测的是本机字体。
- **检测在后台跑完，关掉编辑页也不丢**：检测按窗口在后台登记。检测中关掉编辑页再打开，会接着显示「正在检测」和已经出来的网站结果；再点一次不会重复开一个新的检测。
- **新窗口保存前做的检测也会存下**：新建窗口还没保存时点的指纹检测、深度检测，保存时自动存进这个窗口（检测还没完的，完了再存）。
- **Pixelscan 结论读错修好**：Pixelscan 页面下方的常见问题里有「…your fingerprint is consistent」这句话，扫描还没完成时会被当成结论读成「consistent」，截图也是扫描中途的。现在只认页面标题「Your Browser Fingerprint is …」，显示「scanning…」时继续等。
- **截图更完整**：页面文字连续 3 秒不变才截图（原来 1.5 秒），CreepJS 的「Computing...」也算没加载完；CreepJS 的 WebRTC、设备、网络几栏不会再缺。
- **检测网站弹窗不再卡住**：网站自己弹出的提示框（比如 iphey 接口连不上时的「Failed to fetch」）会自动点掉，并在这个网站的结果里注明；以前会卡到超时、什么都读不到。

## 验证

- 在 Win11 电脑上逐 1.5 秒记录四个检测网站的页面文字：Pixelscan 扫描中「scanning… / Collecting Data…」持续约 11 秒，真实结论约 12.6 秒出现；常见问题里的「fingerprint is consistent」一开始就在页面上。CreepJS 结论后 1.5 秒还在补 WebRTC / 设备栏。iphey 直连时弹「Failed to fetch」。
- 单元测试 413 个（新增：后台检测登记、新窗口保存时存下检测、Pixelscan 扫描中不算结论、Computing... 算加载中）、类型检查全部通过。
