## 新功能：团队

侧栏新增「团队」分页，可以把窗口分配给成员使用，登录态在成员之间自动同步。需要一台自己的团队服务器（基于开源的 PocketBase，部署说明在仓库的 `server/team`）。

- **主账号**：
  - 第一次连接服务器时，用服务器上的初始化码创建，只能创建一次；
  - 可以新建、修改、停用、删除成员，停用后对方立即失去访问权限；
  - 把本机窗口共享给成员，随时改分配或取消共享；
  - 窗口被占着时可以强制释放；
  - 查看日志：谁在什么时间、从哪个 IP 登录、打开、关闭、上传了哪个窗口。
- **成员**：用主账号给的用户名和密码登录，只能看到分配给自己的窗口，点「打开」就会把窗口放到自己电脑上并启动。团队窗口不能修改、复制或导出。
- **登录态同步**：
  - 同一个窗口同一时间只能一个人打开；
  - 打开前自动拉取最新的配置和登录态，关闭后自动上传；
  - 上传失败时，下次打开会先补传；
  - 退出软件时会等上传完成。
- **同步的内容**：浏览器数据目录（不含缓存）。Cookie 在 Windows 上按电脑加密，换一台电脑解不开，所以单独导出后一起传，到对方电脑再导入。保存的网站密码不同步。

## 一键更新

- 不再用隐藏的 PowerShell 脚本替换程序文件：软件先把正在运行的 exe 改名为 `.old`，把新 exe 放到原来的位置，再重新启动。位置和文件名不变，快捷方式照常可用。
- 下次启动时会自动删掉 `.old` 文件和下载留下的安装包。

说明：团队窗口的配置里包含代理和平台账号密码，会下发到成员电脑上使用。界面上看不到，但成员电脑本身能拿到这些信息。
