## 改动

**出口 IP**
- 检测代理成功后，自动用这个窗口的内核和代理在后台打开检测网站，把结果显示在出口 IP 卡片右边：IP 评分、地区（有城市带城市）、厂商、类型（数据中心 / 家宽…）、原生 / 广播。大约 15 秒。
- 以基准网站为准（默认 IPLark），另一个网站（默认 ping0.cc）对照；两边说法不一样时用橙字标出来。网站看到的 IP 和检测到的不是同一个时也会提示。
- 出口 IP 右上角「检测网站」：开关、添加、删除网站，切换基准网站（只有能读出内容的网站能当基准），恢复默认。
- 读不到时（代理太慢、网站要求验证或改版）写明原因，可以重新读取，已保存的窗口可以直接在窗口里打开网站看。
- 「代理 IP」页添加 / 编辑代理时的检测也一样显示 IP 评分。
- 窗口编辑页不再显示旧的「机房网络」等标签，类型以基准网站为准。

**API 提取**
- 检测出的 IP 卡片左边可以勾选，默认勾上：勾上就用这个 IP，检测、保存、重新打开、打开窗口都用它，只有它连不上才从链接取新的；打开窗口时不再因为国家对不上就自动换 3 个新代理，只提醒由你决定。
- 不勾：关掉页面（保存或取消）时，这个代理和它的检测结果、IP 记录都删掉，下次检测或打开再取新的。
- 新建窗口也有「换一个 IP」；再点「检测」复查同一个代理，不会每点一次就从链接取一个。指纹检测、深度检测用的也是这个代理。
- 每个窗口取到的代理只属于这个窗口，另一个窗口用同一条链接也拿不到它。
- 启动日志写明为什么换了代理。

**国家与语言**
- 下拉框里每一项前面加中文国家，后面的原文不变，例如「墨西哥 · español latinoamericano · es-419」「南非 · Afrikaans · af」。
- 选中后框里显示和列表里一样的全部内容，不再缩短；太长换到第二行。
- 新增「键盘布局」：默认跟随语言（例如「墨西哥 · Latin American · es-MX」），也可以从 Windows 的 67 种布局里选；和语言不一致时框里出现一键修正。保存后固定在窗口里，随云端同步。需要 prism9 内核。

**其他**
- 显卡选项去掉内核后缀；选中的显卡、CPU 显示完整型号。
- 出口 IP 下面的提示和卡片一样宽。

## 验证

- 在 Windows 实机上用 prism 内核读取 IPLark 和 ping0.cc：连读两次，每次约 15 秒，评分、地区、厂商、类型、原生都读对。
- 实机测试：取消勾选后保存，代理、检测结果、记录都删除；勾选时保存后重新打开仍是同一个代理；出口 IP 卡片和 IP 评分的显示。
- 单元测试：链接复查同一个代理、换一个 IP、代理连不上才换、打开窗口不因国家自动换、取消勾选后不留记录、键盘布局、IPLark / ping0.cc 的读取规则。
- 用真实 API 链接经加速节点的端到端测试没有跑完（取到的代理 15 秒内没有响应），「检测 → 保存 → 打开是同一个 IP」以单元测试为准，实际使用中再确认。
- 之前的实机测试（编辑页、从代理库选代理、保存后的指纹不变）全部重跑通过。
