## 改动

**通用读取**
- 以前只有 IPLark、ping0.cc 读得出内容，自己加的检测网站只能截图。
- 现在自己加的网站，按页面上的标签认出五项填进面板：评分（评分、风控值、欺诈分数、Fraud / Trust / Risk Score、IPPure 系数等）、地区（国家、Country、城市、City）、厂商（ISP、运营商、Organization、ASN 名称等）、类型（IP 类型、IP 属性、Usage Type、Connection Type 等，按机房 / 家宽 / 移动归类）、原生（原生 IP、IP 来源、Native）。「标签：值」、「标签 Tab 值」、标签下一行是值、JSON 几种写法都认。值照网页原文，不自己编；没认出的那一项写「-」。
- 只读页面上出现检测到的出口 IP 之后的部分：首页上放的别的 IP 的示例数据不会被当成这个 IP 的。
- 面板底下注明「XX 是按页面文字识别的」，附页面截图可以点开核对。
- 用 prism 内核实际打开 12 个常见检测网站核对过：browserleaks、ipapi.is、iplocation.net、ippure、ipdata、whoer 能读出内容；scamalytics、ipqualityscore 要在网址里带 IP 才有结果，ip.sb 页面上几乎没有这些数据。
- 网址里可以写 `{ip}`（比如 `https://scamalytics.com/ip/{ip}`），读取时换成检测到的出口 IP。

**检测网站设置**
- 任何开着的网站都能设为基准网站（以前只能选 IPLark、ping0.cc）。

## 验证

- 单元测试新增：browserleaks 式 Tab 写法、标签下一行写值、JSON、ippure 中文写法、ipdata 优先取信任分、首页示例数据不采用、网址里的 {ip}。
- 实机测试 library-country 新增：自己加的网站当基准时五行照常填、附「按页面文字识别」说明。单元测试、editor-smoke、ip-zone 全部通过。
