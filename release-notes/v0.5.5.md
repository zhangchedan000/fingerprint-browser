## 改动

- **下载位置**：「设置 → 数据与备份 → 下载位置」可以选窗口里下载的文件存到哪（比如 D 盘），默认是系统的「下载」文件夹，「恢复默认」改回来。
  - 打开「按窗口分开」后，每个窗口下载到自己的子文件夹，比如 `D:\下载\18 环境 1`。
  - 下次打开窗口生效。
- **启动器缓存跟着数据目录走**：启动器自身的缓存以前固定在 C 盘 AppData，现在放在数据目录里，数据目录搬到哪它就在哪。升级后第一次启动会自动删掉 C 盘里旧的缓存。
- 仍留在 C 盘、无法更改的只有：记录数据目录位置的小文件（几 KB）、软件更新时临时下载的安装包（装完自动删除）、语言字体包（必须在 Windows 字体文件夹）。
