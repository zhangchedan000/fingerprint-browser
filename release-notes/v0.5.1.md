## 语言字体包

- **在窗口编辑里直接下载**：窗口的系统语言是日语、泰语、阿拉伯语等，而这台电脑还没有对应的 Windows 语言字体包时，「指纹」页「字体」一行会提示，并有「下载字体包」按钮和进度条。
- **来源是微软官方**：字体包取自微软公开的 Windows「语言和可选功能」镜像（26100.1，内核字体名单也来自这里），只下载需要的那一个包（几百 KB 到几十 MB），下载后核对 SHA-256。
- **不需要管理员权限**：字体只装给当前 Windows 用户，和在字体文件上右键「安装」一样。装好后新打开的窗口马上能用，不用重启。
- **支持的语言更多**：除了原来的中日韩、泰、阿拉伯、希伯来、印度各语言，新增旁遮普、奥里亚、僧伽罗、高棉、老挝、叙利亚、切罗基、加拿大原住民文字。
- 「设置 → 常规 → 语言字体」仍可一次下载全部缺少的字体包。
- 去掉了启动时弹出的「安装语言字体包？」对话框。
