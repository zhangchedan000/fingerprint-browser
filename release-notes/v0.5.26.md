## 改动

**指纹设置**
- 所有选择框一样长，放不下的末尾显示「…」，鼠标放上去看全文。
- 有不一致的行，框里靠右出现「⚡ 一键修正」，每行同一个位置；框边变橙，下面一行写原因和会改成什么。没问题的行不显示。联动和以前一样。
- 语言几行跟随国家时直接写国家名，比如「墨西哥 · es-419」。
- 指纹值三行：框里是网站读到的值，下面说明是什么指纹（画布 / 音频 / 元素尺寸）；正常时不再多一行绿字。
- 深度检测单独一张卡片，和指纹检测分开。
- 新窗口和「换一换」的种子不会和本机、团队云端的任何窗口重复（种子决定 Canvas 和 AudioContext 的值）。
- ClientRects 只有 16 种偏移（真实浏览器的尺寸都是 1/64 像素的整数倍），和别的窗口相同属正常，不再报红。

**代理设置**
- 分两块：「代理」（代理方式、快速粘贴、地址、账号密码、网络加速）和「出口 IP」。检测后出口 IP 显示成选中的卡片：IP、国家城市、延迟（按快慢分颜色）、UDP、检测时间；下面接网络身份和「IP 变了时」。
- API 提取多一块「记录」，IP 使用记录和检测记录分两个页签。
- 网络加速：开关开着、加速通道正常时写「经过 某节点」；开关关着不显示标签；开关开着但通道关了或出错，红字说明这个代理连不上。设置里加速通道状态改为「已启用 / 已关闭」。
- 代理 IP 页的添加 / 编辑代理也是同样的出口 IP 卡片。

**基础设置**
- 启动页面：「打开上次关闭的页面」第一次打开时打开下面填的网址，之后恢复上次关闭的页面；「每次打开指定页面」每次都打开这些网址。
- 选平台时自动填平台网址，并切到「打开上次关闭的页面」；换平台会换掉自动填的网址，自己填的网址不动。
- 亚马逊和 TikTok Shop 可以选站点：亚马逊按官方文档的各站点（英、德、法、意、西共用欧洲站），TikTok Shop 有美国和官方列出的 24 个地区。

**其他**
- 内核显示为 Chrome 156 / Chrome 155，内核管理页仍显示完整版本。
- 已保存的密码（平台账号、代理）打开时显示圆点，点小眼睛能看。
- 新建 / 编辑窗口、添加 / 编辑代理等要填写的页面，点旁边或按 Esc 不会关闭，只能点 × 或「取消」。

## 验证

- 新增实机测试：平台网址和站点、自己填的网址不被覆盖、选平台后切到「打开上次关闭的页面」、Esc 和点旁边不关闭、一键修正在框里且每行同一位置、修正后消失、密码显示圆点、出口 IP 卡片。
- 单元测试：种子不和本机及团队窗口重复（从云端拉下来的窗口保留原种子）、第一次打开用填的网址、ClientRects 相同不报红、站点列表、内核名称。
- 之前的实机测试（从代理库选代理、网络加速跟随代理、保存后的窗口只有手动改才会变、指纹值显示）全部重跑通过。
