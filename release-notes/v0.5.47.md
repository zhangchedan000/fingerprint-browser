## 改动

- **内核字体共用、只下一次**：prism16 起的内核带的 Windows 字体（约 900 MB，压缩后约 540 MB），现在放在数据目录的 `kernel-fonts\v1`，所有内核共用，内核目录里只是一个指向它的链接。
  - 已经装了 prism16 内核的电脑：第一次打开窗口时，内核自带的字体直接挪过去，不用下载。
  - 以后的内核包不再带字体（约 200 MB）；装内核时如果电脑上还没有这个字体包，就从 [字体包第 1 版](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/fonts-1) 下载一次。
  - 窗口用到时下载的日文、韩文等语言字体包也放在这里，换内核后不用再下。
  - 删除、更新内核时只删链接，共用的字体不会被删掉。「数据占用」里的内核大小包含这份字体。
- **修正 prism16 内核的识别**：v0.5.46 按内核文件夹名判断是不是 prism16，装好的内核文件夹名里没有这个号，所以「系统版本号固定（Win11 19.0.0 / Win10 10.0.0）」和编辑页「这个语言的 Windows 字体由内核提供」没有生效（字体本身一直用的是内核自带的）。现在按内核的安装清单判断，和其它内核能力一样。

## 验证

- 单元测试 426 个、类型检查全部通过；新加的测试覆盖：第一个 prism16 内核的字体移成共用、第二个内核的字体换成链接且保留它下载过的语言包、不带字体的内核直接链接、数据目录搬家后重新指向、删除内核不影响共用字体。
- 在 Win11 电脑上实测 Windows 目录链接：能识别、能通过链接读到字体，删除内核目录只删链接、共用字体完好。
