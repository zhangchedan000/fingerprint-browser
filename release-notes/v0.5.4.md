## 内核 prism8（相对 prism7）

- **小于本机的分辨率，窗口能拖动**：比如本机 2560×1440、窗口选 1920×1080，以前一打开就顶在最上面、拖不动。现在：
  - 新窗口的默认大小和真实 1080p 显示器上的 Chrome 一样，是 945×1012。
  - 可以随意拖动。
  - 拉大或最大化时，最大只到所选分辨率（1920×1032 可用区域），网页读到的窗口尺寸不会超过屏幕尺寸，不会露出本机真实屏幕。

## 启动器

- **代理新增「API 提取」**：添加代理时选「API 提取」，贴上服务商的提取链接就行。
  - 每次打开窗口都会从链接取一个新代理，并自动识别是 SOCKS5 还是 HTTP。
  - 支持 `IP:端口`、`IP:端口:用户名:密码` 和常见的 JSON 格式。
  - 「检测代理」也会现取一个来测。
  - 白名单模式要先在服务商后台把本机 IP 加进白名单。
- **窗口列表新增「创建时间」**。
- **团队「云端窗口」新增「序号」和「创建时间」**：同名窗口（比如好几个「环境 1」）也能分清，本机删掉后要从云端找回时一眼能认出。新上传或改过的窗口带创建时的序号；更早上传、本机也已删除的窗口，序号可能显示「—」，创建时间显示云端收到它的时间。
