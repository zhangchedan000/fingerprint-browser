指纹浏览器 v0.5.23（Windows x64）。配合新内核 **prism9**：视频编解码跟着所选显卡走、键盘布局跟着窗口语言走；4K 分辨率改为 150% 缩放；去掉不像台式机的选项。

已经装了旧版的话，在「设置 → 关于」点更新即可。配套内核：[prism9](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/prism9)，在「内核管理 → 在线下载内核」里更新。

## 新功能（需要 prism9 内核）

- **视频编解码跟着所选显卡走**：选 RTX 20 系的窗口不再报 AV1 硬件解码（真 20 系没有）；选 RTX 40 / 50 系的窗口报 AV1 硬件编码（真 40 / 50 系有）。RTX 30 系和本机真实显卡不变。
- **键盘布局跟着窗口语言走**：网站读键盘布局时，报这个语言的 Windows 默认布局（微软官方表，348 个语言/地区）。德语窗口是 QWERTZ、法语是 AZERTY、日语有「半角/全角」键；俄语、希腊语等报美式，和真 Windows 上的 Chrome 一样。
- 用旧内核时这两项不起作用，其他照常。

## 改动

- **4K 分辨率按 Windows 默认的 150% 缩放**：真 4K 显示器在 Windows 上默认 150%，网站看到的屏幕是 2560 × 1440、devicePixelRatio 1.5。以前 4K 窗口按 100% 报 3840 × 2160，这种组合很少见。固定窗口尺寸的窗口按比例换算，在显示器上的位置大小不变。
- **去掉 2560 × 1600**：这个分辨率现在主要是 16 寸笔记本，和台式机显卡不搭。已保存的窗口在编辑页提示，一键改成 2560 × 1440。
- **去掉 2 GB、4 GB 设备内存**：内存这么小的电脑上 Chrome 的 JS 内存上限更小，窗口报的却是 8 GB 以上电脑的值，网站能对比出来。已保存的窗口在编辑页提示，一键改成 8 GB。
- **分辨率比这台电脑的屏幕大时提示**：最大化只能铺满这台电脑的屏幕；不要用网页全屏，全屏后网页比屏幕尺寸小，网站能看出来。
- 「浏览器窗口」（窗口尺寸和位置）挪到指纹设置里分辨率下面；「基础设置」里的折叠项改名为「更多设置：标签、颜色、扩展」。
- 编辑页小调整：「指纹检测」和其他分组一样放进卡片；Cookie「从文件导入」按钮间距。
