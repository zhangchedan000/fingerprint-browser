## 代理 IP 的时区

- 各家 IP 数据库对同一个 IP 的时区经常说法不一（美国的 IP 尤其多，比如同一个 IP 有的说美东、有的说美中、有的说美西）。以前每次检测只随机问其中两家，同一个 IP 这次查出来是一个时区，下次又是另一个，照着改了也还会提示对不上。
- 现在检测时同时问 6 家，按多数定时区；票数一样时，看多数数据库给的城市属于哪个时区，再按固定顺序定，不再看哪家先回答。城市也取多数。
- 同一个 IP 定下来的时区会记住（30 天），编辑页、打开窗口、检测指纹用的都是同一个结论；之后哪次回答的数据库少了，也不会改掉。IP 换了才重新判断。
- 窗口时区选的是多数定下的时区：不提醒。选了别的时区：照旧在编辑页提醒、打开窗口时问一次。

## 打开窗口时的时区提醒

- 提醒框标题改成「时区和代理 IP 对不上」，下面多了一个勾选框「知道了，这个 IP 不再提醒（IP 变了会再提醒）」。
- 勾上并继续打开后，这个窗口用同一个出口 IP 时不再弹这个提醒；出口 IP 一变就会重新提醒。这个选择只记在这台电脑上。

## 验证

- 单元测试 472 个、类型检查全部通过。新增：票数打平按城市定、回答顺序打乱结论不变；同一个 IP 记住多数结论；只有多数时区不提醒、其他时区都提醒；勾选后同一个 IP 不再问、IP 变了再问。
- 实测：一个各家说法不一的美国 IP（6 家里 2 家美东、2 家美中、1 家美西），用新的判断方式查了 3 轮、每轮回答顺序打乱，结论都是美东，城市都一样。
