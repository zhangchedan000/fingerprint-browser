## 异地备份（团队 → 服务器，只有主账号能看到）

- **有改动才同步**：窗口关闭、上传登录状态后，1 分钟内把登录状态传到 R2；新建、修改、删除窗口，改分配、改成员后，1 分钟内把数据库传一份。窗口开着时的心跳不算改动，不会频繁写入。
- **每天一次完整同步**：北京时间 03:30，让 R2 上的登录状态和服务器保持一致。被删掉的文件和数据库副本在 R2 上保留 7 天，误删了也能找回。
- **在软件里设置**：点「设置异地备份」，填 R2 存储桶的 S3 API 地址和 API 令牌的两个密钥。服务器会先试写一次，成功了才保存。密钥只存在你自己的团队服务器上，软件里只显示密钥 ID 的前后几位。
- 服务器分页里能看到最近一次同步的时间；同步失败会标红，并显示原因。
- 原来服务器本地的每日备份（03:00，保留 7 份）照常进行。
