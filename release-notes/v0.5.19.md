## 批量操作放在固定位置

- 窗口管理、代理 IP、团队、回收站四个页面统一：批量按钮**一直在工具栏里**，没勾选时是灰的，勾选后变亮；不再在表格上面突然多出一行、把表格往下推。
- 窗口管理：「打开」「关闭」两个常用的直接是按钮，其余（移动分组、批量设置代理、设置 API 链接、检测代理、切换内核、删除）在「批量操作 ▾」里。按钮上显示勾选了几个，下拉里有「取消选择」。
- 代理 IP：「分配到窗口」「检测所选」；团队：「批量分配」「添加到本机」，强制释放和删除云端在「批量操作 ▾」里；回收站：「恢复所选」。
- 分页旁边显示「共 6 条 · 已选 2」。
- 窗口管理工具栏里原来的「批量打开」去掉了（就是批量里的「打开」）；「迁移全部环境 / 统计本地数据」移到搜索框旁边的「⋯」里。

## 表格

- 所有表格按内容定宽：页面放得下就**没有横向滚动条**，窄屏放不下才能左右拖。以前表格右边总能多拖出一点空白，是最后一列的拖动把手超出了表格 5 像素，已修好。
- 窗口列表在 1440 宽的屏幕上一屏放下所有列：代理 IP 完整显示（不再截成「203.0.113.44:10…」），今年的创建时间不写年份。
- 每行操作统一成「常用按钮 + ⋯」：代理是「检测 · 编辑 · ⋯（分配到窗口、删除）」，团队是「打开 · 分配 · ⋯（强制释放、删除云端）」。删除这类操作放进 ⋯，不容易误点。

## 其他

- 代理 IP 页：「删除失效代理」移到「失效」数字卡片上（有失效的才显示），「未检测」卡片上可以直接「检测这些」；没检测过的代理出口 IP 只显示一个「—」。
- 顶部右上角的语言选择去掉了，在「设置 → 常规 → 启动器语言」里改。
