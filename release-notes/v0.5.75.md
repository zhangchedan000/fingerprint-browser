## 点 X 缩到托盘

- 点主界面右上角的 X，主界面缩到屏幕右下角的托盘图标，打开的窗口照常运行。第一次会弹一个提示。
- 点托盘图标打开主界面；右键有「打开主界面」「退出」。再双击桌面图标也会打开主界面。
- 「退出」时还有窗口在运行，会先问一次；确认后关闭所有窗口（团队窗口先上传登录状态），再退出。
- 想点 X 直接退出：「设置 → 常规 → 关闭主界面时」选「退出并关闭所有窗口」。

## 团队窗口

- **同一个窗口同一时间只能在一台电脑上打开**：以前同一个账号在两台电脑上可以同时打开同一个窗口，现在另一台电脑会提示「这个窗口正在另一台电脑「电脑名」上使用，请先在那台电脑上关闭」。登录状态也只认正在用它的那台电脑上传的。主账号的「强制释放」照旧可用。
- **云端备份要先进回收站才能删**：窗口还在窗口列表里时，「团队 → 云端窗口」里不能删它的云端备份，会提示「先在窗口列表里删除（移到回收站），才能删除云端备份」；正在使用的也不能删。批量删除时只删已经进回收站的，其余的跳过并写明。
- 打开团队窗口更快：检查代理和向团队服务器确认（登录、占用、最新配置）同时进行。服务器带来的代理变了，会按新代理重新检查。

## 其他

- CPU：AMD 去掉 26 款不常见的型号，只用常见的 37 款（按全球在用量），显卡档次和年代的搭配规则不变；已经用了这些型号的窗口不变。Intel 不变。
- 改了设置之后，编辑页里之前的检测结果变成灰色，写「设置改了，重新检测后才准」，不再显示成红字。
- 各家 IP 数据库对这个 IP 的时区说法不一时，代理列表、窗口列表和选代理的下拉里加一个灰色小标签「定位不一致」，鼠标放上去能看到各家怎么说、按哪个定的。
