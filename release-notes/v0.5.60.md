已经装了旧版的话，在「设置 → 关于」点更新即可。**这一版要配合内核 [prism21](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/prism21)**：更新后到「内核管理」把 156 / 155 内核更新到 prism21（原地更新，窗口不用重新绑定，指纹值不变）。还想继续用 prism20 的话，请留在 v0.5.59，不要更新。团队服务器不用更新。

## 改动

- **只认 prism21 及以后的内核**：「内核管理」只列出 prism21；窗口用的内核不是 prism21 时，打开或检测会提示先到「内核管理」更新内核。同一 Chromium 版本装了 prism21 时，绑着旧内核的窗口（包括内核名带导入时间后缀的）自动用 prism21 打开。
- **和 Chrome 默认一样**：不再强制打开「始终使用安全连接」（内核自带 HTTPS 自动升级），不再写启动器自己的谷歌搜索引擎（用 Chrome 内置的），有代理时不再关掉链接的 ping。
- **出口 IP 卡片**：切到别的代理方式再切回来，检测结果不再变灰；只有当前代理设置和检测时不一样才变灰，右边的 IP 评分也一起变灰。
- **去掉只给旧内核用的代码**：往这台电脑里装字体、在命令行上直接传指纹参数等（新内核都自带，不再需要）。
