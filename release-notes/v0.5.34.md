## 改动

**「代理 IP」页的 IP 评分**
- 以前：在「代理 IP」页添加或编辑代理，检测后右边的 IP 评分一直报「浏览器环境基础信息格式无效」，评分读不出来，也存不进代理库；只有在窗口里检测才读得到。原因是代理框读评分时内部拼的临时窗口编号是 0，算出来的标记颜色是空的，没通过检查就停了。
- 现在：代理框能正常读评分，读到就存进代理库，用这个代理的窗口都能直接显示。

**窗口里选代理库的代理，没评分就自动读**
- 新建或编辑窗口时选了代理库里的代理（或者打开一个用库代理的窗口），这个代理检测成功过、但没存评分（或存的是旧 IP 的），右边会自动开始读，不用再点「读取 IP 评分」。
- 每个代理、每个 IP 只自动读一次；读失败就显示原因和「重新读取」，不会反复读。

## 验证

- 单元测试全部通过（新增：编号 0、负数等任何编号拼出的窗口都有颜色、都能通过检查）。
- 实机测试 library-country 新增两项：选一个检测过但没评分的库代理，评分自动开始读；「代理 IP」页编辑框点「读取 IP 评分」不再报「基础信息格式无效」（用旧代码跑这一项会失败，报的正是这句）。editor-smoke、saved-fingerprint、ip-zone 也都通过。
