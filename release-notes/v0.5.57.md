## 改动

- **「恢复其他电脑的备份」可以删除某一份**：每一行多了「删除」按钮，确认后只删这一份，窗口和别的电脑的备份不受影响。主账号能删所有人的，成员只能删自己的。删的是本机那份时，下次正常关闭窗口会重新上传一份。
- **看得出是哪台电脑**：电脑名下面显示这台电脑的系统（如 Windows 11 Pro 25H2、Windows 10 Enterprise LTSC 2021 21H2，读自系统注册表），这台电脑下次上传备份后就有；同一个电脑名出现两行时（比如这台电脑的启动器数据重装过），后面加上编号前几位，能分清是哪一份。
- **「添加到本机」只在需要时才问**：云端只有一份备份或没有备份时直接添加，不再弹只有一行的选择框；本机以前用过、云端又有两份以上时才让你选。
- **批量「添加到本机」先选再同步**：选中的窗口里有两份以上备份的，会先弹出一个列表：上面可以一键全部改成「默认规则」「云端最新」或「某台电脑的」，下面每个窗口也能单独选；点「添加到本机」才开始。默认规则和以前一样：本机以前用过的窗口用本机那份，没有的用云端最新的一份。
- **修好：从「API 提取」切到直连 / HTTP / HTTPS / SOCKS5 后，检测和保存还在用 API 链接**：以前在同一个窗口里先填了 API 链接再切回直连，检测出来的是 API 那个代理的 IP，右边 IP 评分报「API 提取的代理类型无效」，保存也可能报错。现在这几种方式检测、保存、读 IP 评分都只用你填的代理（直连就是本机网络）；API 链接还留在表单里，切回「API 提取」时不用重填。
