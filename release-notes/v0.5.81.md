## 深度检测

- **说明文字按网站区分**：whoer 和 Pixelscan 都会写「Proxy: …」，0.5.80 把 Pixelscan 的这一行也配上了 whoer 的说明（「被 whoer 识别为代理」），这是错的。现在每个网站的结果只配自己的说明。
- **Pixelscan 加了自己的说明**：
  - 「Fingerprint is inconsistent」：下面任意一项报红，Pixelscan 就写 inconsistent，看下面具体是哪一项。
  - 「Proxy: Proxy detected」：Pixelscan 按 IP 数据库判断是代理，机房 IP 都会这样，换住宅 IP 才不报；和浏览器指纹无关。
- **只因为代理报红时标「有风险」**：Pixelscan 写 inconsistent、但报红的只有「Proxy detected」（位置、伪装、自动化都正常）时，标签从「不通过」改成「有风险」。有别的项目报红照旧是「不通过」。之前已经检测过的窗口，重新点一次「深度检测」后标签才会变。

## 验证

- 单元测试 506 个、类型检查全部通过。新增：Pixelscan 只报代理时为「有风险」；同一句「Proxy: …」whoer 和 Pixelscan 各配各的说明，自己添加的网站只配通用说明。
- 实测启动器界面：窗口里放一份 Pixelscan 只报代理、whoer 报代理的检测结果，打开编辑窗口：Pixelscan 显示「有风险」和两条 Pixelscan 的说明，whoer 那行还是「被 whoer 识别为代理」（4 项全部通过）；列表和检测网站的界面测试 23 项照旧全部通过。
