## 改动

- **系统版本号跟着电脑走**：窗口和电脑同是 Win10 或同是 Win11 时，报这台电脑的真实值（Win11 25H2/24H2 = 19、23H2/22H2 = 15，Win10 2004～22H2 = 10）；Win11 电脑上的 Win10 窗口报 10.0.0，Win10 电脑上的 Win11 窗口报 19.0.0。指纹检测的期望值也按这个算。
- **另一个 Windows 的字体自动安装**：Win11 电脑开 Win10 窗口、Win10 电脑开 Win11 窗口时，打开窗口前从 prism13 内核自带的 `prism-fonts` 文件夹核对 SHA-256、改名装成当前用户字体（Win10 的表情；Win11 的表情、Nirmala、Sitka、MingLiU ExtB、Segoe Fluent Icons、Segoe UI Variable、Sans Serif Collection、Cascadia），不用联网、不用登录。编辑页字体一行显示「已装好」或提示。13 种语言。
- **155 内核新窗口偶尔弹「偏好设置文件已损坏」修好**：以管理员身份运行时，Chromium 155 启动后会以普通权限重开自己，重开前正在写的 `Local State` 只留下一个空的临时文件，重开的进程把它当成设置文件读，就报损坏（新窗口第一次打开、数据在 AppData 下、装了安全软件时容易碰到；Process Monitor 实测）。现在打开 155 及更早的内核时加 `--do-not-de-elevate`，不再重开；156 本来就在写文件之前处理，不受影响。

## 验证

- 四种情况在两台真机实测（Win11 25H2、Win10 LTSC 21H2），和对应的正版 Chrome / 真 Windows 逐项比：系统版本号、音视频格式、字体名、92 个表情尺寸、表情画布、51 种文字宽度都一样，只差按设计隐藏的字体和测试电脑自己另装的旧字体。
- 155 新窗口：数据放在 AppData\Local 下，不加参数时复现「偏好设置文件已损坏」，加上后连续 5 次都正常。
- 单元测试 408 个、类型检查全部通过。
