指纹浏览器 v0.5.69（Windows x64）。**窗口代理方式选「订阅」时，网络加速开关一选就有。**

## 下载

| 文件 | 说明 |
| --- | --- |
| **Fingerprint-Browser-Setup-0.5.69.exe** | 指纹浏览器安装包 |
| latest.yml、.blockmap | 软件自动更新用，不用下载 |
| SHA256SUMS | 安装包的 SHA-256 |

已经装了旧版的话，在「设置 → 关于」点更新即可。内核用 [prism22](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/prism22)。团队服务器不用更新。

## 改动

- 新建 / 编辑窗口 → 代理设置 → 代理方式「订阅」：「网络加速」开关一选「订阅」就显示（和 HTTP、SOCKS5 一样），不用等选好节点；打开后可以选自动或固定某个加速节点。以前要先选节点才出现。
- 「从代理库选择」不变：选了代理之后才出现（代理库里的代理有自己的加速设置，也可能是不支持加速的 HTTPS 代理）。

## 验证

- 单元测试 464 个、类型检查全部通过；界面截图核对选节点前后都有网络加速开关。
