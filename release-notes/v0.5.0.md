## 内核 prism7（相对 prism6）

- **WebRTC 不再暴露内网和 IPv6 地址**：网页拿到的本机地址是 `xxxx.local`，和正版 Chrome 一样。以前所有 prism 版本都会暴露真实的局域网 IP。
- **WebRTC 真正走代理**：「替换」模式下，SOCKS5 代理支持 UDP 时，WebRTC 经代理收发，网站看到代理 IP，视频通话可用；代理不支持 UDP 时自动退回只报代理 IP、不发 UDP。新增「禁止」模式：网页里没有 WebRTC。代理页「检测代理」会显示代理支不支持 UDP。
- **字体按系统语言**：窗口只显示 Windows 自带字体，加上系统语言对应的语言字体包，本机另装的字体看不到。名单来自微软官方字体列表，并用正版 Chrome 实测补齐。选 Windows 10 的窗口不显示 Windows 11 才有的字体。
- **系统版本**：选 Windows 10 / 11，网站读到的系统版本跟着变（Windows 11 报 24H2/25H2 的真实值）。
- **AudioContext、ClientRects 每个窗口不同**：数值都保持真实浏览器的格式，同一个窗口每次读取一样；也可以设成本机真实值。
- **媒体设备分组**和真实电脑一致。
- 补丁整理为一个功能一个，共 15 个。

## 启动器

v0.4.3、v0.4.4 已经带上了配合新内核的界面（指纹页分组、国家/地区、时区、系统语言、语言字体包安装、WebRTC 四种模式等）。装好 prism7 内核后这些设置就全部生效。

- **重要修正**：v0.4.3、v0.4.4 把 prism6 内核当成支持「WebRTC 走代理 UDP」和「禁止」模式，但 prism6 只改了媒体设备，并不支持。用 prism6 内核时，「禁止」模式和「替换」模式（代理支持 UDP 时）可能暴露真实 IP。这一版只认 prism7 及以上；prism6 及更早的内核，「替换」只报代理 IP、不发 UDP，「禁止」按「隐私」处理。请更新启动器，并把内核更新到 prism7。

- 窗口的系统语言是日语、韩语、繁体中文等时，本机需要对应的 Windows 语言字体包。软件会提示一次，在「设置 → 常规 → 语言字体」可以从微软一键安装（需要确认一次管理员权限）。
