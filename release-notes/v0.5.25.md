## 改动

- **从代理库选代理，国家自动跟上**：新建窗口选代理库里检测过的代理，国家、时区、语言、位置直接按它的 IP 配好，标「基于 IP 生成」，不用再点检测。窗口自己的检测结果仍是空的，不把别处的结果搬过来；在窗口里点「检测代理」会按新结果再配。代理没检测过的，国家不动，提示先检测。在这个新窗口里自己选过国家的，再选代理不覆盖，只提示对不上并给一键修改。已保存的窗口不受影响。
- **语言那几行写清楚跟谁走**：系统语言、字体、语音、媒体设备名，国家来自 IP 的写「随 IP 所在国家」，手动选国家的写「随国家」，单独改过浏览器语言或系统语言的，才写「跟随浏览器语言」「跟随系统语言」。
- **指纹值直接显示网站读到的值**：Canvas、AudioContext、ClientRects 检测过的，下拉框里就是实测值；没检测的显示「每个窗口不同 · 待检测」，下面有「检测实际值」按钮。「换一换」照旧。
- **选好后框里只显示短的**：国家只显示国名，语言只显示代码（如 es-419），显卡和 CPU 只显示型号，时区只显示 UTC 偏移和时区名，媒体设备显示「自动 · 音箱 + USB 耳麦」，代理不显示用户名。展开下拉框还是全的，搜索照旧。
- **每行下面的说明更短、更准**：每行最多一句，只说当前选的选项。改正了几处不准的说法：账号密码同步到团队时会一起同步（原来写只存在本机）；CPU 型号只决定线程数；去掉了没有来源的「台式机最常见」。
- **不一致的地方都有一键调整**：新增 5 处：
  - 分辨率比本机屏幕大：改成放得下的最大常见尺寸，一个都放不下就改为本机真实；
  - 检测出真实值和别的窗口一样：改为每个窗口不同；
  - 老内核的内存对不上：改成网页读到的值；
  - 本机显卡是软件渲染：换一块显卡；
  - 不是指纹内核：改用已装的 Prism 内核。

## 验证

- 新增实机测试「从代理库选代理」：选检测过的墨西哥代理，指纹变成墨西哥，窗口检测结果仍是空的；换美国代理跟着变；选没检测过的代理国家不动并提示；先手动选日本再选墨西哥代理，仍是日本并提示对不上。
- 实机看过选好后框里的短显示和展开后的全文；分辨率比本机屏幕大时出现一键调整。
- 检测结果的新一键调整有单元测试。之前的实机测试（网络加速跟随代理、保存后的窗口只有手动改才会变、指纹值显示）全部重跑通过。
