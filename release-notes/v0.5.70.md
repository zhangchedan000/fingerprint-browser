## 订阅

有的机场限制订阅链接的下载次数，短时间内下载多了会拒绝（403）。这一版：

- **下载过的订阅留在本机**：以前每次打开软件都重新下载；现在用上次下载的节点直接启动，只有点「全部刷新」或改了订阅链接才重新下载。机场临时拒绝时，窗口照常用原来的节点。
- **添加订阅只请求一次**：「获取节点」下载的内容直接用于「添加」，不再下载第二次。
- **「全部刷新」**：订阅没启动起来时（比如被机场拒绝），点它会重新下载、重新启动；以前会提示「未运行」不做任何事。
- **提示原因**：订阅下载失败时，提示里写出机场返回的原因（如「403 Forbidden」）。
- 网络加速里用订阅链接添加的节点也一样。

## 验证

- 单元测试 464 个、类型检查全部通过；用真实代理内核测了：获取节点后添加只下载一次、机场返回 403 时用上次下载的节点照常工作（经过网络加速也可以）、刷新能重新启动、失败原因写进提示。
- 在 Windows 电脑上用真实机场订阅（172 个节点）实测：获取节点、添加、各节点直连 / 网络加速自动 / 固定加速节点的出口 IP 都正确。
