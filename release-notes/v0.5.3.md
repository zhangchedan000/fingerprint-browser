## 改动

- **指纹值显示真实读数**：Canvas、AudioContext、ClientRects 三行下面显示网站实际读到的值和检测时间；没检测过时有「检测实际值」链接。点「换一换」后会自动重新检测，新值几秒后出来。
- **字体可以选**：「跟随系统语言」（默认，Windows 自带字体加该语言字体包，缺字体包时报红并可直接下载）或「本机真实字体」（这台电脑装的所有字体，包括你另装的）。同一语言的窗口字体相同属于正常，检测不再报红。
- **MAC 地址用真实厂商编号**：前 3 段取自 IEEE 官方注册表（华硕、微星、技嘉、华擎、Intel、Realtek、Killer，跟着显卡档次选），写法和 Windows 一样是 `00-1B-21-3A-5C-7E`，旁边显示品牌。macOS 窗口用 Apple 的编号。
- **深度检测**
  - 等网页完全加载完再读结论和截图，不会再截到 BrowserScan 还在加载的页面。
  - iphey 判为不可信时，显示它判断的位置和 IP，通常就是扣分原因（比如它的 IP 库把 IP 判到别的国家）。
  - 检测网站可以自己管理：点「检测网站」，每个都能开关、删除，可以添加新网站（只截图和显示标题），「恢复默认」回到 iphey、BrowserScan、Pixelscan、CreepJS 四个。
  - 结果会保存在窗口里，关掉编辑页再打开还在，并显示检测时间；设置改过会提示结果可能过时。
  - 点网站链接，直接在这个窗口里打开：窗口开着就新开标签页，没开就按这个窗口的代理和指纹启动并打开这个网站。
