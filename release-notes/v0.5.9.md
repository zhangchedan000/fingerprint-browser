## 每个窗口单独的网络加速

窗口的「代理设置」里新增一行 **网络加速**，和「设置 → 网络加速」用的是同一套节点：

- **开关**：这个窗口连代理时要不要先经过你的加速节点。关掉就直接连代理。
- **加速模式**：「自动选择最低延迟」（每 5 分钟测速，自动用最快的节点）或「手动固定」。
- **加速节点**：选「手动固定」后出现下拉框，列出你在设置里添加的所有节点和延迟，选哪个就一直用哪个。

每个窗口单独设置，互不影响：同一个代理，可以这个窗口走加速、那个窗口直连；不同窗口也可以同时走不同的节点。

「添加代理」「编辑代理」「批量导入」里也有这一行，作为这个代理的**默认值**：在代理页点「检测」时按它连接；把代理分给窗口时，窗口先用这个设置，之后可以在窗口里单独改。代理列表的「类型」下面会显示「加速 · 节点名」。

- 打开了网络加速，但加速通道没开时，会提示「获取不到代理 IP（网络加速未开启）」，**不会偷偷用本机 IP 直连**。
- 「设置 → 网络加速」里选的节点，现在是新窗口和新代理的默认节点。
- 已有的窗口升级后走法不变（加速开着时国外代理走加速、国内代理直连），在窗口里改过一次后就按你的设置走。
- HTTPS 类型的代理暂时不能走网络加速，这一行不显示。

## API 提取代理

- 识别代理是 SOCKS5 还是 HTTP 时，也按窗口的网络加速连接。以前这一步总是直连，只接受境外 IP 的服务商会拒绝，提示「既不是 SOCKS5 也不是 HTTP 代理」，窗口也打不开。
- 代理服务器拒绝连接时，直接显示它给的原因，比如「拒绝了连接：msg: forbidden ip=… not supported」，一看就知道是 IP 不被接受。
- 用法：在服务商后台把**加速节点的 IP** 加进白名单，窗口里打开网络加速、「手动固定」到这个节点。

## 检测代理后自动配好国家和语言

在窗口的「代理设置」里点「检测代理」并且成功后，「国家/地区」自动切到「基于 IP 生成」：时区、浏览器语言、地理位置按代理 IP 所在国家生成，系统语言改为跟随浏览器语言，字体、语音、媒体设备名也跟着变。没有点检测就保持原来的设置。
