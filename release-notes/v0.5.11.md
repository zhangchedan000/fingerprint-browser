## 检测代理

- **最多 15 秒**：不通的代理 15 秒内就返回失败，并写明原因（连不上、超时、账号密码错、被代理服务器拒绝），不再自动重试。以前最坏要等两分钟左右。
- **关掉再打开就能重新检测**：检测还没出结果时关掉编辑页，重新打开不会一直转圈；旧的结果回来了也会丢掉。
- **轮换用 6 个查 IP 的网站**（ipwho.is、ipapi.co、ipinfo.io、geojs.io、ip.sb、ipapi.is），每次随机挑两个对比；某个被限流（HTTP 429）就自动换下一个，很少再出现「无法交叉确认」。
- **两个网站只是城市不一样时，以国家为准**，不再显示可疑的城市（比如「美国 Frankfurt」）。
- **轮换代理说清楚**：两个网站看到的出口 IP 不一样时，直接提示「这个代理每个连接换一个出口 IP（轮换代理）」，并建议在代理商后台改成固定会话（粘性 IP）。以前写的是「GeoIP 数据源冲突」，同一件事还会显示两个提示框，现在只显示一个。
- **已经创建的窗口，检测代理不会再改国家、时区和语言**。只有新建窗口时检测成功，才自动切到「基于 IP 生成」。已有窗口和 IP 对不上时会提醒，并给一个「改成和 IP 一致」按钮，由你决定。

## 窗口里直接填 API 提取

窗口「代理设置」的代理方式新增 **API 提取**：粘贴服务商的 API 链接，下面就是网络加速和「检测代理」。保存时自动存进代理库，代理库里已有同一个链接就直接用那一条。

## 加速节点显示出口 IP

- 「设置 → 网络加速」的节点列表新增「出口 IP」一列，可以一键复制，方便填到代理商的白名单。
- 窗口和代理里的「加速节点」下拉框，每个节点后面都带出口 IP。
- 代理列表「类型」下面显示「加速 · 节点名 · 出口 IP」。
- 出口 IP 在加速通道启动和「测速」时查询，会保存下来。
