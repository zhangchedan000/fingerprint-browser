指纹浏览器 v0.5.43（Windows x64）。**Win10 / Win11 窗口在 iphey 上各种语言都不再报「inconsistent browser fingerprint (butterfly)」**，窗口只用自己那版 Windows 的原版字体。配套内核 **[prism15](https://github.com/zhangchedan000/prism-kernel-releases/releases/tag/prism15)**，请在「内核管理 → 在线下载内核」更新。

## 改动

- **另一版 Windows 的全套字体**：Win10 和 Win11 的系统字体有 80 多个文件版本不同（Arial、Times New Roman、Segoe UI、Calibri、Tahoma、Malgun Gothic、Yu Gothic、Microsoft JhengHei、表情、符号等）。prism15 内核带上两套原版（Win10 85 个、Win11 87 个文件），在 Win11 电脑上开 Win10 窗口（或反过来）时，启动器把另一版的整套字体改名装成当前用户字体，内核让窗口每个字体都先用自己那版的。
- 用 prism13 / prism14 内核时只装那两个内核用得到的几个字体（和以前一样）。

## 验证

- 两台电脑（Win10 LTSC 21H2 / Win11 25H2）各建一个干净的临时 Windows 用户，按启动器同样的方式装好字体后测：Win10 窗口、Win11 窗口在 iphey 上 14 种语言（韩语、英语、西语、简繁中文、日语、俄语、德语、法语、葡语、阿拉伯语、泰语、越南语、印地语）全部 Trustworthy 100。
- Win10 电脑上的 Win11 窗口：表情的画布像素和真 Win11 完全相同。
- 单元测试、类型检查全部通过。
