## 改动

**代理 IP 库的检测结果共用**
- 存进「代理 IP」库的代理（窗口保存时手动填的普通代理也会自动进库），只有一份「最近一次检测」和 IP 评分。在任何地方检测它——代理页、任一窗口的编辑页、窗口列表的批量检测、打开窗口前的检测——都更新这一份。
- 所有用到它的地方都显示这份最新的：代理页的「编辑代理」一打开就有结果（不再是「还没检测」）；用它的每个窗口、新建窗口选它、在新窗口里手动填或粘贴同一个代理（地址、端口、账号、密码都一样）时，出口 IP 卡片和 IP 评分直接显示，并注明「代理 IP 库里这个代理最近一次的检测，用它的窗口都一样」；窗口列表的「代理 IP」一列和打开前的「IP 变了」提醒也按它。
- 编辑页开着时别处重新检测了，这里也会换成新的结果。
- 取消勾选「保留这次检测结果」后关掉页面：这次检测和 IP 评分作废，代理库里这个代理回到检测前的样子（不是这次测的就清掉）。
- API 提取不变：每个窗口各自独立，不进代理库。
- 说明：v0.5.20 曾改成「检测结果只属于检测它的窗口」，这一版按新的要求改回代理库共用。

**IP 评分后台读取**
- 读取 IP 评分（IPLark、ping0.cc）放到后台：读完之前关掉编辑页、点保存、或者直接打开窗口，都会接着读完并存到这个代理上（API 提取的存到那个窗口上）。
- 同一个代理正在读的时候，别的地方打开它显示「正在读取」，读完自动出来，不会重复去读。

**指纹检测**
- 两个窗口 ClientRects 相同时的提示改为「偏移的种类有限」（prism11 起 64 种，之前 16 种），仍属正常。

**配套内核 prism11**
- 透明底的 WebGL 图、Canvas 半透明彩色边缘：每个边缘像素改不改由它和周围 8 个像素决定（以前只看透明度，透明 WebGL 图在 10 个窗口里只有 6 种结果）。
- 音频：每 23～39 个采样改 1 个、幅度 61 档；同一个窗口里每个改动都让采样离 0 更远（或都更近），网站加的是绝对值，所以不会抵消回真实值（以前网站统计的 500 个采样里只改到 5 个左右，会有重复）。
- ClientRects：每个方向 1～8 个 1/64 像素（64 种，以前 16 种）。
- 其他项目数值不变；已有窗口在这三项上的值会变一次（相当于浏览器升级），之后固定不变。
