## 新建列自动匹配数据

- 列设置里「新建列」填名字时，会按名字找表里已有的数据：比如填「出口 IP」「IP」「时区」「延迟」「城市」「运营商」，就自动对上，每一行直接显示这项数据，不用自己填，点表头也能按它排序。
- 名字下面多了「内容」下拉：自动对上的不对，可以手动改成别的数据，或者选「自己填写」。没对上的，就是每行自己填（和以前一样）。
- 已经被别的自己新建的列用掉的数据，不会再出现在下拉里，也不会再被自动匹配。
- 能选的数据：
  - 窗口：出口 IP、国家 / 地区、国家代码、州 / 省、城市、IP 时区、运营商、ASN、延迟、最后检测、代理地址、代理类型、时区、语言、分辨率、显卡、CPU、CPU 核心数、内存、内核版本、标签、启动网址、平台账号、平台、修改时间；
  - 代理 IP：出口 IP、国家 / 地区、国家代码、州 / 省、城市、IP 时区、运营商、ASN、主机、端口、代理账号、备注、IP 评分、IP 类型、原生 IP；
  - 订阅节点：国家 / 地区、国家代码、州 / 省、城市、IP 时区、运营商、ASN、最后检测、所属订阅、UDP、IP 评分；
  - 团队云端窗口：最后上传、数据大小、更新时间、备注。
- 列设置里自己新建的列后面会标出它显示的是哪项数据（自己填写的标「自定义」）。

## 深度检测

- **whoer 成为内置的第 6 个检测网站**：读它的评分（100% 为好，60% 以上为一般，再低为差），并把扣分项写出来：DNS 服务器和 IP 不在同一个国家、IP 所在地的时间和浏览器时间不一样、被识别为代理 / 匿名服务 / 在黑名单里。自己添加过 whoer 网址的，会直接按内置规则读评分；以前改过检测网站清单、清单里没有 whoer 的，在「检测网站」编辑里它会显示为「内置网站，不在列表里」，点「加入」即可。
- **自己添加的检测网站**：
  - 以前页面还没出结果就截图了；现在会等页面的内容稳定下来再截图（至少等 15 秒，最多 45 秒）。
  - 页面上有分数、百分比一类的行，会摘出来显示在结果里。
  - 没有可读的评分时，标签显示「只截图」，不再像出错。
- **截图截整页**：以前只截了窗口里看得到的一屏，现在从上到下截整个页面（特别长的页面最多截前 12000 像素，并会注明）。
- 结果里的网址靠左对齐，各网站的缩略图大小统一。
