## 以 IP 的实际落地位置为准

- IP 数据库定位置有两种办法：一种按这段 IP 的登记地址，一种实际测网络延迟。机房 IP 常常登记在一个地方、机器放在另一个地方，这时按登记地址的几家会一起说错。
- 例：一个机房 IP，几家数据库按登记地址说在肯塔基州（时区美东或美中），实测定位的说在洛杉矶；从服务器追踪路由，它确实在洛杉矶。0.5.73 按多数定成了美东或美中，而且看哪家这次回应了，结论还会变。
- 现在：各家说法一致，照旧；说法不一致时，以实测定位（ipinfo.io）的城市、时区和坐标为准；它这次没回应，才按多数定。同一个 IP 定下来的结论照旧记住。
- 出口 IP 卡片的时区一行会写明各家的分布和「以实测定位为准」。
- 窗口时区和这个结论一致就不提醒；不一致照旧提醒，可以勾「这个 IP 不再提醒」。

## 验证

- 单元测试、类型检查全部通过。新增：说法不一致时以实测定位为准（带上它的城市和坐标）；它没回应时按多数；实测定下的结论不会被之后按票数的结论改掉。
- 实测：上面那个机房 IP，用新规则查 3 轮（其中两轮有一家数据库被限流没回应），结论都是洛杉矶。
