## 国家和时区按 IP 配，不再停在默认值

- 以前检测代理时同时问 6 家 IP 数据库，但定国家只比前两家：只要第二家说的国家不一样，就算其余几家都一致，也当成「说法冲突」，新窗口不按 IP 配，停在默认的「美国、英文、纽约时区」。默认国家刚好是美国时连提示都没有，结果 IP 在洛杉矶的窗口时区是纽约，被检测网站判成时区不符。
- 现在按多数定国家：说某个国家的数据库最多，就按这个国家配时区、语言和位置。几家正好打平时，按启动器最信的那家（按网络线路实测位置的那家）定；它不在打平的几家里，就按排在最前的那家。窗口直接按这个结果配好，不用再手动选。
- 数据库说法不一时，编辑窗口的代理设置里会显示一行「IP 数据库对这个 IP 在哪个国家说法不一：……；已按 X 配」，后面有每个国家的按钮（带时区），想换成另一个国家点一下就行。换过去以后，「国家和 IP 不一致」「时区和 IP 不一致」的检查按你选的这个国家算，不会再报。
- 已经建好的窗口不会自动改。窗口的时区和 IP 对不上时，编辑页「时区」那行照旧有「改成和 IP 一致」。

## 深度检测加上 Fingerprint.com

- 深度检测默认 5 个网站：iphey、BrowserScan、Pixelscan、CreepJS，加上 Fingerprint.com。
- Fingerprint.com 显示篡改分数（0～1，网站自己的标准是 0.8 以上算防关联浏览器），下面列出它判中的项目，每项带说明：是否判为篡改、浏览器特征罕见程度、可疑总分、VPN（时区不符、系统不符、公开 VPN、匿名中继、模型判断，分开列）、代理（机房还是住宅、哪家）、虚拟机、IP 黑名单等。
- 结论按网站自己的标准：判为篡改、防关联浏览器、特征异常、恶意机器人、IP 在黑名单里是「不通过」；VPN、代理、虚拟机等是「有风险」；都没有是「通过」。
- 以前改过检测网站列表的，列表里不会自动多出 Fingerprint.com：在「检测网站」里会看到它，点「加入」。
- 同一个 IP 短时间内访问 Fingerprint.com 太多次，网站会暂时拒绝，过一两分钟再测。

## 验证

- 单元测试 491 个、类型检查全部通过。新增：6 家数据库里 1 家说别的国家时按多数定国家、时区按多数那边；多数和排第一的那家不一致时按多数；打平时按实测位置的那家定、各个国家和时区都留着；时区检查和国家检查认可切换过去的国家；轮换 IP 照旧不按 IP 配。Fingerprint.com 的读取用真实页面原文测过（正常、判中代理和虚拟机、篡改 0.97、特征异常）。
- 用测试版实测（独立的测试数据，不碰正在用的窗口），用的是之前被设成纽约时区的三个节点，每个新建一个窗口：

  | 节点 | 以前的窗口 | 这次新建的窗口 | Fingerprint.com 篡改分数（以前 → 现在） |
  | --- | --- | --- | --- |
  | 美国 01 | 美国、纽约 | 美国、洛杉矶（和 IP 一致） | 0.727 → 0.091 |
  | 美国 03 | 美国、纽约 | 美国、洛杉矶（和 IP 一致） | 见下面说明 |
  | 日本 03 | 美国、纽约 | 日本、东京、日语（和 IP 一致） | 0.286 → 0.037 |

- 美国 03 这次时区已经和 IP 一致，Fingerprint.com 仍报「时区不符」、分数 0.94：它按同一个 IP 过去 7 天的访问记录判，测试当天这个 IP 上开过好几次纽约时区的窗口。所以 IP 一旦被很多时区不对的访问用过，换对时区也要过几天才恢复，这也说明窗口一开始就要配对。
- 深度检测在测试窗口里跑完 5 个网站，Fingerprint.com 的分数和判中项都读到了。
