## 改动

**同一国家、不同时区的 IP**
- 以前窗口固定以后，换 IP 只比国家：比如 API 窗口原来的 IP 在德州（中部时间），换了一个华盛顿州的 IP（太平洋时间），都是美国，就不提醒；网站却能看出浏览器时间和 IP 所在地差 2 小时（检测网站报「location data inconsistent」）。
- 现在编辑页「时区」那行会黄字提醒：「代理 IP 的时区是 太平洋时间 · America/Los_Angeles，窗口是 中部时间 · America/Chicago，网站能看出时间和 IP 所在地对不上」，框里的「一键修正」把**时区和经纬度**改成新 IP 的，国家、语言、语音、字体都不动。
- 按 Windows 上 Chrome 实际报的时区比较：底特律和纽约在 Windows 上是同一个时区，不会误报。
- 打开窗口前也会检查：「IP 变了时」选「阻止启动并确认」的窗口和 API 提取的窗口会先问你（可以继续打开）；选「仅提醒」的只记日志，照常打开。

**旧的检测结果不再显示成「一致」**
- 指纹检测记着当时的出口 IP。现在的出口 IP 和检测时不同，「时区」「WebRTC」两行的检测结果变灰，写明「检测时的出口 IP 是 …，现在是 …，请重新检测」，不会再显示上一个 IP 的「与代理 IP 所在地一致」。
