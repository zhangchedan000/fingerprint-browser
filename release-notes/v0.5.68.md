## 修复：订阅链接取不到节点

- 用订阅链接添加的订阅，第一次要先下载；以前下载完之前就判成「没有可用节点」，所以节点数一直是 0。现在会等下载完（最多 20 秒）再取节点。
- 已经加过、节点数是 0 的订阅，更新后打开软件会自动重新下载，不用删了重加。
- 网络加速里用订阅链接添加节点也是同样的问题，一起修了。

## 先获取节点，再添加

代理 IP → 订阅 →「添加订阅」，和 设置 → 网络加速 →「添加节点」，都改成两步：

1. 填好订阅链接（或粘贴节点链接），点 **「获取节点」**：下面列出取到的节点（节点名称、协议）和总数。取不到会直接显示原因（比如链接下载失败、里面没有能用的节点），什么都不保存。
2. 看过没问题，再点 **「添加」**。改了链接要重新获取；编辑时只改名称可以直接保存。

新建 / 编辑窗口 → 代理设置 → 代理方式「订阅」：「选择订阅」右边一直有 **「添加订阅」** 按钮，也是同样两步；加好后自动选中这个订阅，接着选节点。

## 其他

- 窗口经过网络加速使用订阅节点时，直接用已经下载好的订阅，不再重复下载。
- 网络加速的本机端口挑选时同时检查 TCP 和 UDP 都空闲，避免和别的程序撞端口。

## 验证

- 单元测试 464 个、类型检查全部通过；用真实代理内核测了：获取节点（订阅晚一会儿才返回、粘贴节点链接、下载失败的链接，失败几秒内就报原因，什么都不保存）、添加后能用、经网络加速能用。
