## 为什么改

在 Fingerprint.com 上实测：同一个 IP、同一套硬件，只改这三项。

- 用噪音（每个窗口不同）时，分数取决于这个窗口碰上的噪音值，同样的配置从 0.005 到 0.32 都有。
- 用本机真实值时，四套不同硬件都稳定在低分：香港机房 IP 0.009～0.031，墨西哥住宅 IP 0.005～0.019（Chrome 156）。
- 窗口之间不会因此被认成同一个：硬件不同的窗口即使这三项完全相同，仍然是不同的访客。硬件完全相同、IP 相同的窗口，开不开噪音都会被认成同一个。

## 改了什么

- **新建窗口**：「指纹值」里的 Canvas、AudioContext、ClientRects 默认是「本机真实（推荐）」。需要的话，每个窗口仍可改成「每个窗口不同」。
- **已有窗口不会自己变**：以前建的窗口保持原样。要改的话，在窗口列表勾选窗口，点「批量操作 → Canvas / AudioContext / ClientRects」，选「本机真实（推荐）」或「每个窗口不同」后点应用。只改这三项，字体和显卡的设置不变。正在运行的窗口，关闭后重新打开才生效。
- **一键随机指纹**：换显卡、CPU、屏幕，不再把这三项改回噪音。
- **批量导入**：「disabled_spoofing」这一列留空时按新的默认值（这三项用真实值）；填 `none` 表示全部用噪音。
- **指纹检测**：这三项用真实值、和别的窗口相同时显示正常（和真实 Chrome 一样），不再提示「改为每个窗口不同」。

## 验证

- 单元测试 509 个、类型检查全部通过。新增：新窗口默认三项真实、批量设置三项（字体和显卡不变、重启后还在）、批量导入空列和 `none`、指纹检测里真实值相同为正常。
