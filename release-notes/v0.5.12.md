## 窗口打开过后，指纹固定

- **新建窗口和以前一样**：检测代理后，「国家/地区」按 IP 自动联动，时区、语言、地理位置跟着配好。
- **第一次打开窗口时锁定**：这次打开实际用的国家、时区、语言、经纬度存进窗口；「跟随本机」的屏幕分辨率和 CPU 核数也存成当时的具体值。以后每次打开都用这些值，不再跟着 IP 或电脑变。
- **IP 对不上只提醒，不自动改**：
  - 再点「检测代理」，IP 的国家和窗口的国家不一样时，提示并给「改成和 IP 一致」按钮，点了才改，改完同样固定。
  - 打开窗口时 IP 在别的国家：「出口变化时」是「阻止启动并确认」的，会先问你是否继续；不会改窗口的时区和语言。
- **「国家/地区」显示具体国家**，后面有小标签：按 IP 选出来的写「基于 IP 生成」，自己在下拉框里选的写「手动选择」。时区、语言这些都跟着国家联动，显示具体值。
- 以前是「基于 IP 生成」的老窗口：升级后下次打开时，按那次的 IP 固定下来，看起来和现在一样。
- 设备名称和 MAC 地址保存窗口时存成具体值。

## API 提取改成窗口自己的

- API 链接**只存在窗口里**，不再放进代理库（代理库里那条只会显示最后一个很快就失效的 IP，选了也没法复用）。在窗口「代理设置」选「API 提取」粘贴链接即可；「添加代理」里不再有「API 提取」。
- **升级时自动迁移**：代理库里原来的 API 代理，把链接复制进用它的每个窗口，然后从代理库删除，窗口照常能用。
- **记录每次用过的 IP**：每次打开窗口取到的 IP、国家、城市都记在窗口里（最近 50 条），在「代理设置」能看到「IP 使用记录」；窗口列表显示「API · 上次 IP」。
- **API 代理不再因为「IP 变了」而被拦**：每次打开 IP 本来就不同，只对比国家；国家和窗口一样就直接打开。
- 窗口管理里勾选多个窗口，可以「设置 API 链接」一次改好。
