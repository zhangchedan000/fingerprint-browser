## 改动

**出口 IP 卡片**
- 左边每项单独一行，不再挤在一起、互相盖住：位置（国家 · 省 / 州 · 城市）、时区、坐标、网络（AS 号和机构）、运营商、延迟、UDP、定位来源、上次 IP（出口变了时），以及检测时间、提取地址等。
- IP 后面标出 IPv4 / IPv6。

**勾选**
- 从代理库选的、手动填的代理，检测结果也可以取消勾选（以前只有 API 提取的可以）。取消后卡片变成虚线，写明「不保留：关闭页面后删除这次检测结果」。
- 关掉页面（保存或取消）时，没勾选的这次检测结果、IP 评分都不留：窗口上没有这次检测，代理库里这个代理的状态也回到检测前的样子。代理本身照常保存。
- 勾选并保存：普通代理照常进「代理 IP」库；API 提取的不进库，只留在这个窗口上。每个窗口取到的 API 代理只属于这个窗口，另一个窗口用同一条链接不会拿到它的 IP 和记录。

**配套内核 prism10**
- Canvas：透明底上的彩色文字和图形（BrowserLeaks 的 Canvas 图、CreepJS 的表情符号和 WebGL 图）以前在同一台电脑的所有窗口上是同一个值，现在每个窗口不同。
- 音频：CreepJS 读的分析器（AnalyserNode）数值以前所有窗口一样，现在每个窗口不同，并且和音频结果对得上。
- 已有窗口在这两项上的值会变一次（相当于浏览器升级），之后固定不变；以前就有噪音的项目数值不变。

## 验证

- 实机（启动器）：出口 IP 卡片每项一行；取消勾选后关掉页面，重新打开窗口没有这次检测。
- prism10 在 RTX 3080 Ti 上 156、155 都实测：上述几项两个窗口不同、关掉重开不变；各种读法之间的关系和不加噪音时完全相同；BrowserLeaks 两个窗口签名不同；CreepJS、BrowserScan、Pixelscan 开噪音和本机真实值结果相同。
- 单元测试全部通过；编辑页实机测试（editor-ux、editor-smoke）通过。
