指纹浏览器 v0.4.0（Windows x64）。从这个版本开始改成**安装版**，以后的更新在软件里一键完成。内核没有变化，继续使用 v0.2.0 里的两个 prism5 内核；旧版本都保留，随时可以退回。

## 下载

| 文件 | 说明 |
| --- | --- |
| **Fingerprint-Browser-Setup-0.4.0.exe** | 指纹浏览器安装包 |
| latest.yml、.blockmap | 软件自动更新用，不用下载 |
| SHA256SUMS | 安装包的 SHA-256 |

## 从免安装版换到安装版（只需要一次）

1. 关掉正在运行的免安装版（`Fingerprint.Browser.0.x.x.exe`）。
2. 下载并运行 `Fingerprint-Browser-Setup-0.4.0.exe`。默认装在当前用户目录，不需要管理员权限，会创建桌面和开始菜单快捷方式「指纹浏览器」。
3. 打开后，原来的窗口、内核、代理、团队登录都还在：数据目录没有变（例如 `D:\指纹浏览器`）。
4. 确认没问题后，旧的免安装版 exe 可以删掉。

免安装版里的「设置 → 关于 → 更新」装不了这个版本，请按上面的步骤手动安装。

## 一键更新

- 安装版用 electron-updater 更新：在「设置 → 关于」检查到新版本后点「下载更新」，下载完成后会用发布里的 latest.yml 校验 SHA-512；点「立即重启并更新」，软件会退出，在后台静默安装，装好后自动打开新版本。
- 不再用 PowerShell 脚本替换程序文件，也不用等程序文件解锁。之前火绒拦截、免安装版锁住自身 exe 导致更新失败的问题都没有了。
- 更新前要先关闭全部浏览器窗口；团队窗口的登录态会先上传完，再开始安装。
- 已在本机验证：装好 0.4.0 → 检测到新版本 → 下载并校验 → 静默安装 → 新版本自动启动。
